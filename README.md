# Ресоциализация — образовательный навигатор 2.6

[Открыть опубликованный сайт](https://step3dlab.github.io/resoc/)

Интерактивный каталог образовательных программ для участников проекта «Ресоциализация»: поиск и фильтры, пошаговый подбор, избранное, сравнение, источники и анализ охвата Москвы и Московской области.

## Данные

- 12 557 записей образовательных программ;
- 10 620 записей по Москве;
- 1 878 записей по Московской области;
- сведения сопровождаются ссылками на источники и ограничениями проверки.

## Публикация на GitHub Pages

В репозитории размещена статическая версия сайта. Каталог, подбор, избранное и сравнение работают непосредственно в браузере. AI-чат требует серверной части и поэтому в версии GitHub Pages отключен; вместо него доступны каталог и пошаговый подбор.

Полная размещенная версия проекта: [resoc-navigator-v2.step3d.chatgpt.site](https://resoc-navigator-v2.step3d.chatgpt.site/).
