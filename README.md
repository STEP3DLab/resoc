# Ресоциализация — образовательный навигатор 2.8

[Открыть опубликованный сайт](https://step3dlab.github.io/resoc/)

Интерактивный каталог образовательных программ для участников проекта «Ресоциализация»: поиск и фильтры, пошаговый подбор, избранное, сравнение и персональный маршрут.

## Что обновлено в версии 2.8

- мобильная навигация перестроена без пересечения подписей;
- дополнительные разделы доступны через компактное меню «Ещё»;
- панель вида, размера выдачи и ссылки на подборку адаптирована для экранов от 320 пикселей;
- плавающие элементы больше не перекрывают карточки;
- десктопная сетка и полная боковая навигация сохранены.

## Данные и функции

- 12 813 записей образовательных программ;
- 163 программы РГСУ с условиями кампании 2026/27, статусом цены и бюджетных мест, контактами и официальными ссылками;
- маршрут из трёх программ с документами и следующими действиями;
- подготовка обращения по выбранным программам в приёмную комиссию РГСУ;
- голосовой ввод в поддерживаемых браузерах.

GitHub Pages размещает статическую версию. AI-чат требует серверной части и поэтому здесь отключён; каталог, подбор, маршрут, избранное и сравнение работают в браузере.
