# Ресоциализация — образовательный навигатор РГСУ

Рабочий прототип сервиса поддержки выбора образовательной и профессиональной траектории для участников проекта «Ресоциализация».

## Что можно проверить

- четырёхшаговый сценарий предварительного подбора;
- объяснимые рекомендации и ограничения;
- поиск и фильтры по каталогу образовательных программ;
- карточку программы и переход к официальному источнику;
- демонстрационный сценарий обращения к специалисту.

## Статус

Прототип предназначен для экспертного тестирования. Он не сохраняет персональные данные, не осуществляет юридически значимых действий и не гарантирует поступление или трудоустройство. Сведения о программах необходимо подтверждать у образовательных организаций.
